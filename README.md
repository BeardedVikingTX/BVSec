## ⚔️ Who We Are

**BVSec** is the security forge of **BeardedVikingTX** — bug bounty hunter, hacker, coder, and builder of things that refuse to sell your soul to advertisers.

## 🔐 Security First

This isn't a marketing slogan. It's an engineering mandate.

- **Prepared Statements** — Every SQL query. No exceptions.
- **Output Escaping** — Every user-controlled value, every time.
- **CSRF Tokens** — On every state-changing request.
- **CSP Headers** — Strict Content Security Policy by default.
- **Input Validation** — Server-side, always. Client-side is UX, not security.
- **Zero Trust Architecture** — Never trust the client. Never.

Found a vulnerability in one of our products? **We want to hear from you.**

📧 **Security Contact:** `security@beardedviking.org`
🔑 **PGP Key:** Available on request

We practice responsible disclosure and credit researchers who report valid issues.

## 🚀 Getting Started

### Prerequisites

- PHP 8.2+
- MySQL 8.0+ / MariaDB 10.6+
- Composer
- Node.js & npm (for asset compilation)
- A web server (Apache or Nginx)

### Local Setup

```bash
# Clone the forge
git clone https://github.com/BVSec/BVSec.git
cd BVSec

# Install PHP dependencies
composer install

# Install frontend dependencies
npm install

# Configure environment
cp config/config.example.php config/config.php
# → Edit config.php with your DB credentials

# Import database schema
mysql -u root -p bvsec < database/schema.sql

# Build assets
npm run build

# Launch local server
php -S localhost:8000
```
Visit `http://localhost:8000` and you're in.
